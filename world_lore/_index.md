# world_lore — index

> One line per file: what it covers, and how far to trust it. **Read the file itself before using it** — these lines are signposts, not summaries.
>
> **Status key:** **Canon** = established at the table · **Settled** = DM ruling, not yet seen by the players · **Proposal** = designed but not yet approved or used · **Reference** = background or legend · **Stale** = known to be out of date (see the note).
>
> Open questions about any of these live in `sessions/Decisions.md`; the present state of everything is in `sessions/Campaign State.md`.
