Drop character art in THIS folder, then re-run:

    python3 make_stat_cards.py

Filenames it looks for (.jpg, .jpeg or .png all work):

    vaskar          <- https://dl2.myminifactory.com/object-assets/64c7d6990a35f0.68517096/images/01_Bandit%20Khan.jpg
    juggernaut      <- https://dl2.myminifactory.com/object-assets/64c7c72d49f653.73478572/images/10_Iron%20Juggernaut_Side.jpg
    ironwake_thug   <- https://dl2.myminifactory.com/object-assets/64c7d39c8418d5.68420090/images/03_Bandit%20Scrapper_1.jpg

    fen_guard       durgan      anselm      denrick
    yarel           slave       servant     ysabel      reference

Anything missing falls back to a generated emblem, so the PDF always builds.
Images are centre-cropped to fill the panel (roughly 3:2 landscape works best).
