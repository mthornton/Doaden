# Decisions
### Every open DM decision in the campaign, in one place

> **How this file works.**
> - **This is the only decisions list.** Lore and prep files no longer carry their own "Open decisions" sections; they point here.
> - **Open** items carry a recommendation (mine, not canon) and the file/section they affect.
> - **When Michael settles one:** move it to **Settled** with the date and a one-line ruling, then write the ruling into the source file as plain text (rewrite the section cleanly, don't stack a "SETTLED" note on top), and update `Campaign State.md` if it changes the present.
> - **When play overtakes one**, move it to Settled as *overtaken* with what happened.
> - Built Oct 2026 by collecting the lists from 20 files. Items are grouped by when you need them, not by file.
