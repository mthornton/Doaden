**Note:** These are the Forbidden Psalm (warband) versions of the Doaden adventures. ## Overview
This archive catalogs all 28 Forbidden Psalm skirmish-wargame adventures in the Bestiarum collection, mapping each to its 5E counterpart adventure so the DM can quickly cross-reference plot and faction details. Use the table below to look up an FP adventure's premise and key foes; consult the corresponding 5E summary file for full NPC stat blocks, encounter tables, and session-planning detail.

## Notes
- Most of the Part 1 set (Burial Isle, Rise of the Jailer, Man Eaters Pt2, Calden Keep Pt1/Pt2, Bloodfever, N'Gorroth, The Remade, Siege of Sturmenburg Pt1/Pt2, Deadmire, Eternal Legions Pt1) are built as three linked mini-scenarios telling one continuous story, closely mirroring their 5E counterpart's plot beats but compressed into skirmish objectives (survive N rounds, escort an NPC, break down a door, kill a boss) rather than exploration/dialogue. Man Eaters Pt1 is the outlier — a single stand-alone "survive the night" scenario, not a three-part arc.
- The Remade's title page is oddly labeled "A 5e Compatible Adventure / Suitable for Levels 5-10" even though the whole document uses Forbidden Psalm warband mechanics throughout (HP/Morale/Armor stat blocks, Agility/Strength/Presence tests) — almost certainly a copy-paste template error in the source PDF's cover page, not a sign the file is actually the 5E version. Treated it as the FP text.
- Indictum Dominus has the sharpest narrative swerve of the set: after the boss fight (Aspect of the Jailer) it pivots into a betrayal scenario where the Penitent Crusade itself attacks the warband to cover up its involvement — a plot thread (Crusade corruption) that also colors Calden Keep Pt2's Sol Blade mission.
- OCR-quality caveats (Part 1 set): Calden Keep Pt1, Indictum Dominus, and Man Eaters Pt2 were read from OCR'd text (some garbled decorative headers/glyphs, e.g. stray "NUN" artifacts on title pages) — goals, rewards, and stat blocks were legible and used as-is. Man Eaters Pt1 (device-side .ocr.txt) had similar minor header noise but clean scenario/stat-block text.
- OCR-quality caveats (Part 2 set): Prison Breakdown, Yaga's Brew, Mycena Mortifera, Siverfell Ruins, Crimson Harvest, and Giant's Cradle had scattered artifacts (e.g. "JHE" for "THE", "¢" for bullet points, misread ligatures) but content was clear enough to extract sensibly without invention.
- Prison Breakdown is structurally different from the rest of the set: it contains two unconnected one-shot adventures (Iron Gauntlet riot / Urvakh, and the Panopticon / Iron Juggernaut) rather than a single three-chapter narrative.
- Several adventures (Braying Call, Grim Harvest, Siverfell Ruins, Crimson Harvest) hinge on branching player choices (spare/kill NPCs, drink or refuse, end curse or not) that affect rewards/consequences — worth flagging for DM prep since outcomes diverge.
- All FP stat blocks use the lightweight Forbidden Psalm system (HP/Morale/Weapon/Armor/Special) rather than 5E stat blocks; treat these as reskins to be converted if running the FP version, not drop-in 5E monsters.
